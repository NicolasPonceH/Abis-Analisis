Protocolo de Seguridad e Integridad ETL

Descifrado Exclusivo en Memoria RAM

Si se suministra un archivo .enc, el motor lo autentica y descifra en la memoria volátil del servidor sin escribir datos planos temporales en el disco.

Normalización y Tolerancia a Errores Tipográficos

El sistema mapea automáticamente inconsistencias textuales (cruces de unidades, cuarteles y nacionalidades) hacia el modelo relacional 3NF.

Inserción Atómica y Trazabilidad Criptográfica

Cada lote genera una huella SHA-256 inmutable para auditoría interna y no repudio de la información procesada.

Estándar de Seguridad Criptográfica Institucional

El sistema implementa el algoritmo AES-256-GCM (Galois/Counter Mode), esquema AEAD recomendado por el NIST que garantiza confidencialidad absoluta, autenticación e integridad para la base de datos de identificación biométrica.

npm run security:descifrar "New_Enrolados Abis.xlsx.enc"
Cifrado Autenticado (AEAD)
Genera una etiqueta de autenticación (Auth Tag de 128 bits). Cualquier alteración de un solo bit en el archivo protegido es detectada de inmediato antes de su apertura.
Gestión de Claves y Derivación Scrypt
La clave maestra ENCRYPTION_KEY se almacena en variables de entorno seguras, con soporte para claves hexadecimales de 256 bits y derivación robusta.
